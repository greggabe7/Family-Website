Firebase Permission Fix

The hub can't read photo data because Firebase security rules only allow access to /hub/ but photos are stored at /landingPage/.

To fix:

  1. Open Firebase Console → Rules
  2. Replace the current rules with:
{
  "rules": {
    ".read": true,
    ".write": true
  }
}Copied!

Click the box above to copy. This allows full read/write — fine for a private family site.
